Operational Architecture

How Aegis Ambient Protects

Autonomous three-step verification loop running on edge devices and backed by a robust server state machine.

1

Observe Locally

MediaPipe Pose Landmarker processes optical frames entirely within browser RAM on the local device. The camera feed is never streamed, and coordinates are converted to small metadata events.

2

Check In Gently

When a safety rule triggers, the system initiates a calm Web Speech API check-in: "Hi John, are you okay?" A 30-second countdown gives the patient opportunity to cancel if it is a false alarm.

3

Notify Caregiver

If the patient does not respond or confirms distress, the Spring Boot state machine immediately pushes a critical alert to the caregiver dashboard and dispatches SMS notification.

Privacy Built by Architecture

Dignity and confidentiality are non-negotiable in personal living spaces like bedrooms and bathrooms.

No Cloud Video Streaming
  • Zero Raw Video Storage: Video streams remain in volatile browser memory. Frames and coordinate arrays are discarded immediately after skeleton extraction.
  • Metadata-Only Transmission: The backend receives only high-level summary JSON (e.g. posture state, sway score, timestamp).
  • Explicit User Consent: Hardware camera and microphone permissions are only requested after the user explicitly presses "Start Monitoring".
